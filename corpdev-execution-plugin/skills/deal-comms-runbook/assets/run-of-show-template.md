# Asset — Day-of Run-of-Show (template)

Sequences the announcement day. Fill timing relative to signing/close and market hours. Owner:
**Comms**. Every row has an owner and a go/no-go check; nothing fires early.

## Pre-day (T-minus)
| When | Action | Owner | Status |
|---|---|---|---|
| T-3 to T-1 | All assets drafted + **approved**; tracker green | Comms | |
| T-1 | Final go/no-go with Deal Sponsor, Legal/IR, People Ops | Deal Sponsor | |
| T-1 | Seller-employee comms staged; manager talking points distributed (tent) | People Ops | |

## Announcement day (sequence, not necessarily one day)
| Order | Window | Action | Owner | Go/no-go |
|---|---|---|---|---|
| 1 | Early | Seller employees notified (all-hands / message) — **before public** | People Ops + Deal Sponsor | ✔ before step 4 |
| 2 | Early | Toast internal all-hands + Slack | Comms + Deal Sponsor | |
| 3 | Pre-market (if material) | 8-K filed (Item 1.01) | Legal/IR | ✔ before public |
| 4 | Market open / pre-market | Press release + blog live; website banner | Comms / Web | |
| 5 | +30 min | Customer comms sent; FAQ live | Product Marketing + GTM | |
| 6 | +1 hr | Social amplification | Social | |
| 7 | Same day | IR/analyst outreach | IR | |
| 8 | Day of / +1 | AMA / fireside | Deal Sponsor | |

## Contingency
- Leak before T-0 → invoke accelerate trigger (leak playbook); compress steps 1–4.
- No-go at T-1 → hold; all assets stay tent-only; reschedule.

## Close-day (Stage 6, if separate from signing)
- Internal + customer **close-confirmation** note; banners/status updated; Item 2.01 8-K if material.
  Minimal external posture — the story was told at signing.
