# Module — Stockholder Package & Financial / Tax / Accounting Close-Out

Two sub-modules. The stockholder section is in scope whenever the target has equity holders to pay;
the financial section is **always** in scope (consideration moves at every close).

---

## A. Stockholder package — Owner DRI: **Legal** (instruments) + **Corp Dev** (payment mechanics)

These are legal instruments. The skill tracks them as required items and flags status; **Legal /
outside counsel draft them.** Do not generate the legal text.

- **Stockholder approval** — written-consent solicitation or information statement; drag-along
  execution where applicable; appraisal/dissenters'-rights handling. P0.
- **Letters of transmittal** — collected from holders to receive consideration.
- **Payment spreadsheet** — consideration allocation per holder. **Must tie to the cap-table
  waterfall** (from `cap-table-analyst`). This is the most error-prone artifact; reconcile totals to
  the purchase price and to the flow-of-funds. P0.
- **280G analysis + cleansing vote** — only if golden-parachute exposure (accelerated equity to
  disqualified individuals). Long-lead; start at signing.
- **FIRPTA certificates** — only if foreign sellers.
- **Debt payoff letters + lien releases** — only if target debt is repaid at close. P0.

## B. Financial / Tax / Accounting close-out — Owner DRI: **Finance / Tax / Accounting**

- **Estimated closing statement** — pre-close estimate of cash, debt, transaction expenses, and the
  **net-working-capital (NWC) peg**, with the post-close true-up methodology and window (typically
  60–90 days). P0 for funds flow.
- **Escrow / holdback** — indemnity escrow and/or NWC-adjustment holdback set up and funded.
- **Treasury funding** — purchase-price funding source confirmed; bank signatory changes staged.
- **Purchase price allocation (PPA) & intangibles valuation** — **long-lead, start at signing.**
  Third-party intangibles valuation takes weeks. Sets up the opening balance sheet and goodwill.
- **ASC 805 transaction-cost treatment** — confirm: business combination → transaction costs
  **expensed** as incurred under US GAAP; tax treatment may diverge (IRC §263 capitalization),
  creating a deferred tax asset. Asset acquisition → different rules (capitalize). Confirm structure
  before close so the accounting is right Day-1.
- **Tax structure & elections** — finalize stock vs. asset vs. 338(h)(10)/336(e); withholding setup;
  transfer taxes; equity-comp tax treatment; new-state payroll registrations.
- **Opening balance sheet + ERP onboarding** — target set up in chart of accounts / ERP; cutoff
  procedures.
- **Insurance** — add target to Toast policies effective at close (D&O tail for the target's board,
  GL, cyber, E&O); bind R&W policy if used.

## In/out summary for the plan
- Stockholder section in **if** there are equity holders to pay. Sub-items (280G, FIRPTA, payoff
  letters) gated by their own triggers above.
- Financial/tax/accounting section **always in**. PPA and 280G are the long-lead items — flag to
  start at signing.
