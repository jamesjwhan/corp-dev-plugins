# Scenario Model Template

*Structure and guidance for the financial-diligence skill, Step 5.*

---

## Principles

**Anchor bear/bull to historical range, not round numbers.**
If NRR has ranged from 104% to 127% over the past 3 years, use those as the bear/bull bounds —
not 90% and 130%. Scenarios built on arbitrary assumptions are not useful. Scenarios built on
the actual observed volatility in the data show the team what range of outcomes is plausible.

**One driver at a time, then combined.**
Before building the combined 3-case model, run a single-variable sensitivity on each key driver.
This shows which inputs move the needle most, which the team should focus diligence effort on.

**Management's model is the base case — don't rebuild it.**
Use management's projections for the base case exactly as presented. Bear and bull are
departures from that, not from your own independent projection.

---

## Key Drivers (in order of typical impact)

1. **ARR growth rate** — usually the highest-impact driver; small changes in growth compound quickly
2. **NRR** — directly drives ARR without incremental S&M spend; high-leverage
3. **Gross margin** — affects both the profitability runway and unit economics
4. **S&M efficiency** — drives new logo growth and cash burn simultaneously
5. **Burn rate / G&A leverage** — matters most for companies burning > $5M/year
